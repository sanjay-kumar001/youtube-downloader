# YouTube Downloader — Audio & High-Quality Video

A Python command-line tool powered by [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) for downloading **audio or video you are authorized to save**. It supports single videos, playlists, selectable playlist entries, configurable quality, retry handling, duplicate prevention, and JSON run reports.

> **Responsible use:** Use this tool only for content you own, have permission to download, or are otherwise legally allowed to save. Follow applicable laws and YouTube's terms. This project does not bypass DRM, paywalls, or access controls. The project is independent and is not affiliated with or endorsed by YouTube.

## Features

- Audio-only downloads in the best available source format, or conversion to MP3/M4A.
- Video plus audio downloads up to a chosen resolution (720p through 8K), subject to source availability.
- MKV (default) or MP4 output containers for video.
- Single-video and playlist workflows, including playlist item selection.
- Download archives to skip previously downloaded media IDs.
- Retries, progress output, error summaries, and timestamped JSON reports.
- Portable filenames and video IDs in filenames to reduce collisions.
- Python 3.10+ and `uv`-based setup.

## Requirements

- Python 3.10 or newer.
- [`uv`](https://docs.astral.sh/uv/) for environment and dependency management (recommended).
- FFmpeg available on `PATH` for MP3/M4A conversion and merging separate video/audio streams.
- Internet access and a supported URL.

### Ubuntu / Debian setup

```bash
sudo apt update
sudo apt install -y ffmpeg curl ca-certificates
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Open a new terminal if needed, then clone and set up the project:

```bash
git clone https://github.com/sanjay-kumar001/youtube-downloader.git
cd youtube-downloader
uv sync
```

`uv sync` creates the virtual environment, installs the project and dependencies, and creates or updates `uv.lock`.

Verify the setup:

```bash
ffmpeg -version
uv run youtube-downloader --help
```

If you prefer not to install the command entry point, you can run `uv run youtube_downloader.py --help` instead.

## Quick start

Use a URL for content you are authorized to download. Keep URLs quoted, especially if they contain `&`.

```bash
# Best available audio stream
uv run youtube-downloader "VIDEO_URL"

# Convert audio to MP3
uv run youtube-downloader "VIDEO_URL" --format mp3

# Download video up to 4K, merged into MKV
uv run youtube-downloader "VIDEO_URL" --mode video --resolution 2160

# Download a playlist as MP3
uv run youtube-downloader "PLAYLIST_URL" --playlist --format mp3

# Download selected playlist entries
uv run youtube-downloader "PLAYLIST_URL" --playlist --playlist-items 1-5
```

Downloads go to `downloads/` by default. For all options and detailed examples, see **[USER_MANUAL.md](USER_MANUAL.md)**.

## Common options

| Option | Default | Purpose |
|---|---|---|
| `--mode audio\|video` | `audio` | Download audio only or video with audio. |
| `--format best\|mp3\|m4a` | `best` | Audio output choice; MP3/M4A conversion uses FFmpeg. |
| `--quality 128\|192\|256\|320\|0` | `320` | MP3 bitrate target; use with `--format mp3`. |
| `--resolution best\|720\|1080\|1440\|2160\|4320` | `2160` | Maximum video height; `2160` is 4K and `4320` is 8K. |
| `--video-container mkv\|mp4` | `mkv` | Container for merged video/audio. |
| `--playlist` | Off | Enable playlist downloading. |
| `--playlist-items 1-5` | All items | Download selected playlist positions; requires `--playlist`. |
| `--output PATH` | `downloads` | Set the output directory. |
| `--retries N` | `5` | Retry attempts for supported network/file operations. |
| `--archive PATH` | Automatic | Set a custom download archive. |
| `--report PATH` | Automatic | Set a custom JSON report path. |
| `--verbose` | Off | Print more diagnostic details. |
| `--help` | — | Show all CLI options. |

A resolution is a **maximum**, not a promise. The source must provide a compatible stream at that resolution. `--resolution best` removes the explicit height cap. MKV is the safer default for preserving a broad range of source codecs without re-encoding.

## Troubleshooting

- **`ffmpeg` not found:** install FFmpeg and confirm `ffmpeg -version` works.
- **`No module named yt_dlp`:** run `uv sync` from the repository directory.
- **Requested resolution unavailable:** use a lower cap or `--resolution best`.
- **Playlist selection rejected:** include `--playlist` with `--playlist-items`.
- **YouTube extraction changes:** update yt-dlp with `uv lock --upgrade-package yt-dlp && uv sync`, then retry. Platform changes may temporarily affect downloads.
- **Download is skipped:** check the archive file in the output directory. Use a separate archive for independent audio/video workflows.
