# Security Policy

## Reporting a vulnerability

Please do not report sensitive security issues in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. If it is not enabled, contact the repository maintainer privately through a verified contact method listed on the GitHub profile.

## Scope

This is a local command-line application that relies on third-party dependencies, including yt-dlp and FFmpeg. Keep dependencies updated and avoid running untrusted modified copies of the project. Never publish account cookies, authentication tokens, or private URLs in issues or logs.
